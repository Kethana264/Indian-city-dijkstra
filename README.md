# Dijkstra algorithm on Indian cities

## Introduction

This program makes use of the Dijkstra's algorithm to solve for the shortest path between Indian cities.

The problem is derived from the road map search problem in the book. In contrast to the cities in Romania, Indian cities are usedhere.

## Problem

The starting point is Hyderabad and the ending point is Bengaluru.

The cities are interconnected using weighted roads, with the weight corresponding to the road distance in kilometers.

## Algorithm Used

The Dijkstra's algorithm is used to compute the shortest path.

The algorithm uses the starting city as the base and selects thenext closest city repeatedly. Then, the distance to the neighboringcities are updated accordingly.

## Cities Used

- Hyderabad
- Kurnool
- Pune
- Nagpur
- Chennai
- Bengaluru

## Result

Shortest Path:

**Hyderabad → Kurnool → Bengaluru**

Distance:

**570 km**
